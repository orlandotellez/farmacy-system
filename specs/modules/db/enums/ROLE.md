# `ROLE`

Roles de usuario en el sistema.

| Valor | Descripción |
|-------|-------------|
| `admin` | Administrador — acceso total (usuarios, settings, bitácora) |
| `farmaceutico` | Farmacéutico — valida recetas, supervisa catálogo e inventario |
| `cajero` | Cajero — opera el punto de venta y facturación |
| `bodeguero` | Bodeguero — compras, lotes y movimientos de inventario |

Default en el schema: `cajero`.
